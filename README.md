# 🧠 Stroke Risk Predictor
A machine learning web app that predicts stroke risk based on patient data.

## 🔗 Live App
(https://stroke-predictor-pf2vzqkxtkfwv5eqca5vtj.streamlit.app/)

## 📌 Project Overview
- Dataset: Stroke Prediction Dataset (Kaggle)
- Model: Random Forest (tuned with GridSearchCV)
- Precision: 0.914 | Recall: 0.967 | Accuracy: 0.938

## 🛠️ Tools Used
- Python, Pandas, Scikit-learn, SMOTE
- Streamlit (deployment)
